# Original Classic raid-warning sound

RaidWarning.ogg is Blizzard Entertainment's World of Warcraft raid-warning audio,
sound kit 8959, file data ID 567397. It is the original default death-alert sound.
The game's audio remains copyright Blizzard Entertainment; it is not covered by
the Deathlog license.

Source: https://www.wowhead.com/classic/sound=8959/raidwarning
Audio: https://wow.zamimg.com/sound-ids/classic/enus/101/567397/RaidWarning.ogg
Source SHA-256: 647dacc622e9d5695ee9a341a77229b11fc7a6274ea92cad31e66bf62e89e3c7

The 100% clip is an unchanged copy. The 10-90% clips change only audio gain so
HardcoreBuddy can control this alert's volume without changing WoW volume CVars
or affecting other addons. Rebuild using scripts/import_raid_warning_sound.py.
